# Expected Result Summaries

This directory stores compact reference outputs from the current manuscript run.

The full raw simulation directories are intentionally not committed because they are large and can be regenerated from `configs/` with `scripts/reproduce_paper_results.py`.

- `proposed_full_sweep/`: 4 Hz CASSA full-sweep command-filter/projection summaries.
- `crazyflow_replay/`: 255-run Crazyflow replay summaries and the current `table_9_crazyflow_replay.csv` reference.
